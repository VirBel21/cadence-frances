# Cadence · francés desde cero (versión de prueba)

Curso de autoestudio de francés para hispanohablantes. Sitio estático: no necesita servidor ni base de datos.

- `index.html`: la plataforma (Hoy, Sonidos, Escenas, Repaso, Método).
- `tests.html`: pruebas automáticas; la pestaña debe decir PASS.
- `robots.txt` y la etiqueta `noindex`: mientras sea versión de prueba, no se indexa en buscadores.

El progreso se guarda solo en el navegador de cada persona. No hay cuentas, cookies ni estadísticas.
No certifica ningún nivel ni está vinculado a una universidad.
